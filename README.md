# Sistema de Gestión de Empresa de Buses 🚌

Un sistema de software desarrollado en Java para la administración de las operaciones y la gestión comercial de una empresa de transporte de pasajeros. 

## 📚 Contexto Académico
Este proyecto fue diseñado y programado como trabajo central para la asignatura de **Programación Orientada a Objetos (POO)**. El enfoque principal del desarrollo fue la correcta aplicación de los pilares del paradigma (encapsulamiento, herencia, polimorfismo y abstracción) estructurando una lógica de negocio sólida.

## ⚙️ Arquitectura y Metodología
* **Modelado Iterativo:** La estructura del sistema se construyó en base a un **diagrama UML** que sirvió como columna vertebral del diseño. Este modelo no fue estático, sino que fue sometido a revisiones y actualizaciones iterativas en cada entrega del proyecto para adaptarse a los nuevos requerimientos.
* **Implementación Selectiva de GUI:** Para optimizar el desarrollo y centrar el esfuerzo en la robustez de la lógica subyacente, las Interfaces Gráficas de Usuario (GUI) fueron diseñadas e implementadas de manera estratégica **solo para ciertas clases específicas** (las de mayor interacción con el usuario final). El resto de las entidades operan de manera interna procesando los datos.

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Java
* **Paradigma de Diseño:** Programación Orientada a Objetos (POO)
* **Arquitectura:** Modelado de software mediante diagramas UML
